# 🏎️ Lorenzo Kart

Jogo de corrida de kart em 3D que roda direto no navegador, feito pelo Lorenzo com a ajuda do Claude.

**Jogar:** https://smduarte1977.github.io/lorenzo-kart

- 5 pistas: Vale Verde, Deserto Dourado, Pico Nevado, Vulcão Furioso e Galáxia Neon
- Blocos da sorte ❓ com itens: ⚡ Turbo, 🍌 Banana, 🚀 Míssil, 🌩️ Raio
- Faixas de turbo, garagem com upgrades e escolha de cor do kart
- Sons, 3 músicas de fundo e tela cheia com o celular deitado

Controles no celular: ◀ ▶ para virar, ▲ para acelerar, RÉ e o botão de item.
No computador: setas ou WASD, espaço para usar o item, F para tela cheia.
